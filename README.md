## Key Principles Observed in This Corpus

- Preserve prior versions; do not silently overwrite.
- Classify claims (empirical, mathematical/model, historical, interpretive, philosophical/theological, speculative).
- A citation supports only the claims it directly addresses; topical relatedness is insufficient.
- Distinguish structural analogy / metaphor from established mechanism, ordinary coupling from physical quantum entanglement, operational capacity from phenomenal experience.
- Use Pass / Fail / Indeterminate gates. Indeterminate is never Pass.
- No simulation or numerical result is claimed without execution record, parameters, outputs, and reproducibility materials.
- Do not invent sources, data, or completed validations.
