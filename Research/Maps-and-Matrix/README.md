# Maps & Matrix

Versioned maps of the research corpus: a **claim map**, the **625-intersection matrix** (Alchemy × Being × Phase × Lens, per `Research/README.md` §9.3–9.4), a **link graph** of the seven reports with GAIA as the motherthread at the centre, a **cross-cycle change log**, and a **data model** (JSON Schemas) with validation of all data against it.

Each version is a separate folder and is never overwritten; a later cycle adds a new version.

| Version | Folder | Covers | Generated by | Status |
|---|---|---|---|---|
| v1 | `v1-cycles-0-1/` | Cycle 0 (Baseline v2) and Cycle 1 (x3) | `Research/tools` (gaia_tools 0.1.0, data model 1.0.0) | Branch `research/maps-c0-c1` (PR into `research/cycle-1-x3`) |
| v2 | `v2-cycles-0-2/` | Cycles 0, 1 and 2 (x6) | `Research/tools` (gaia_tools 0.2.0, data model 1.1.0) | Branch `research/cycle-2-x6` (PR into `research/maps-c0-c1`) |

Everything here is generated from the cycle folders by `Research/tools` (`python -m gaia_tools.maps`), so the maps can be regenerated and checked. The labels used are the framework's four: **E** Established · **P** Plausible · **PS** Philosophical/Spiritual · **H** Hypothetical. GAIA as motherthread is a Philosophical/Spiritual organizing principle and is kept separate from scientific findings.
