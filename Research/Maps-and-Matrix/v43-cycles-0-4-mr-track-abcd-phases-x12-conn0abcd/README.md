# Maps & Matrix — v43 (adds the Connection report, x12, to v38)

**Tooling:** `tools/conn.py maps` in `Research/Tracks/Connections/E1-Soul-Spirit-Subconscious-Consciousness/`. It runs `python -m gaia_tools.phases maps` unchanged, then adds the overlay below. Earlier versions (v1 to v38) are kept unchanged.

## What changed
- All base files (`claim_map/`, `matrix/` except one added column, `graph/` except added edges, `changes/changes.csv`, `simulations/`) are regenerated by `phases maps` from the same inputs as v38. `data-model/` and `validation/` are copied from it unchanged, plus `validation/connection_x12.json`.
- `matrix/connection_claim_placement.csv`: 35 Connection claims placed on the Being axis by the topics they connect (Soul, Spirit, Mind for the Subconscious, Consciousness) and on lenses by the provisional keyword rule.
- `matrix/connection_factor_x_topic.csv`: 13 judged factors × 4 topics, with basis claim IDs. Factors in all four topics: F01, F02, F04, F07.
- `matrix/connection_pairs_6.csv`: the six topic pairs, with shared factors, shared cited sources, cross-citations in the existing ledgers and Connection links.
- `matrix/intersections_625.csv` gains the column `connection_claims_in_being_lens_projection` (116 claim placements on Being × Lens pairs, each repeated across the 25 Alchemy × Phase cells of that pair, 2900 in all; a claim connecting several topics counts on each of their Being rows; claims with no keyword lens are not counted). The 625 grid is not re-dimensioned; Alchemy and Phase stay unassigned for these claims.
- `graph/link_graph.json` gains 28 CL-* edges between the existing topic nodes SOUL, SPIRIT, SUBC and CONS (the base graph had one such edge, TL-08).
- `changes/connection_changes.csv`: claim and link changes for this Connection cycle.

## Honest limits
- Factors, claims and links are one agent's judgments; gate INDETERMINATE (independent review pending).
- Lens placement uses the provisional keyword rule (a navigation aid, not a classification).
- Placing a claim on a Being row says which topics it connects, not that it shows anything about a soul, spirit or mind.

```
cd Research/Tracks/Connections/E1-Soul-Spirit-Subconscious-Consciousness

```
