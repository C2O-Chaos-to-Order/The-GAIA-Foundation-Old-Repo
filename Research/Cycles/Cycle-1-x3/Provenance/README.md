# Provenance (Cycle 1)

- `SOURCE_REGISTER.csv` — 115 sources (37 added in Cycle 1; column `cycle_added`), with access mode, retrieval URL, date, HTTP status and SHA-256 of the fetched snapshot. Third-party text is not redistributed.
- `FETCH_LOG.jsonl` — every Cycle-1 retrieval attempt, including failures (e.g. V10, V08/V22 full text).
- `MANIFEST.sha256` — SHA-256 of every file in this cycle folder except itself.
