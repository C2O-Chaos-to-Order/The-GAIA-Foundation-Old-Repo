# Claims

`claims.csv` columns: `claim_id`, `report`, `wording`, `claim_class` (repository class), `framework_label` (Established / Plausible / Philosophical/Spiritual / Hypothetical), `conclusion_status` (repository status; mapping in `../../FRAMEWORK.md` appendix), `source_ids` (simulation evidence cited per check as `SIM-Rn-C0#Ek`), `locator`, `confidence`, `counterevidence_limits`, `cross_links`, `verification_phrases` (`SOURCE|regex` pairs re-checked against a live re-fetch in `../../Verification/`).
