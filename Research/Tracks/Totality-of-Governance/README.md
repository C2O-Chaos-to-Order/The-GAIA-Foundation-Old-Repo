## Rules for this track

- Cycle folders are kept exactly as delivered. Corrections go in a new version beside the old one, never over it.
- A gate is PASS, FAIL or INDETERMINATE as its own record states. INDETERMINATE is never shown as PASS, and a failed pre-registered check stays recorded as failed.
- Claims carry one of the four labels: Established, Plausible, Philosophical/Spiritual, Hypothetical.
- `tools/build_maps_v44.py` builds Maps & Matrix v44 from v43 plus the ToG 1 files.
