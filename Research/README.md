## Versioning and evidence rules

- New versions/addenda preserve provenance; earlier versions are not overwritten unless explicitly specified.
- A research-grounded design proposal is not equivalent to empirical validation of the complete architecture.
- Source claims must be audited individually; a source is not evidence for claims it does not directly support.
- Named literature in the v4.0.0 source-anchor ledger is a verification queue until primary-source claim-level review is complete.
- Hypergraph topology or spectral descriptors are diagnostics only; the representation, Laplacian, baseline, and interpretation must be declared before numerical claims.
- No simulation or numerical validation is claimed without an execution record, parameters, outputs, and reproducibility materials.
- Implementation remains unauthorized unless explicitly approved.
