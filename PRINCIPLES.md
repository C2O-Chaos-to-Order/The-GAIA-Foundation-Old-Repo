# Founding Principles of The GAIA Foundation

## Principle 1: Truth with Integrity

> "Truth with Integrity. A Truth That Is Never Twisted.
> I Don't Like Truth If It Is Allowed to Be Twisted."
>
> — Kyle Alexander Steen, owner, 2026-10-25

**Label:** Owner commitment (a founding value set by the owner, not an empirical claim).

What it means in practice, using rules this repository already follows:

- Sources, data and results are never invented. A citation supports only the claims it directly addresses.
- Indeterminate is never reported as Pass. A pre-registered check that fails stays recorded as failed and is not rerun to make it pass.
- Every claim carries its label (Established, Plausible, Philosophical/Spiritual or Hypothetical), so a belief is never presented as a fact.
- Prior versions are preserved, not silently overwritten, so any change to the record stays visible.
- Diminishing returns and limits are reported honestly, not hidden.
